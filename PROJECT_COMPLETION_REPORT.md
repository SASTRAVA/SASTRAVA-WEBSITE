## 🎓 HOW TO CUSTOMIZE

### 1. Change Company Name (2 minutes)
- **File**: `src/components/layout/Navbar.jsx`
- **Line**: 20
- **Change**: `<span className="font-bold text-xl">SASTRAVA</span>`

### 2. Update Colors (5 minutes)
- **File**: `tailwind.config.js`
- **Gold colors**: lines 20-25
- **Peacock colors**: lines 26-31
- **Edit hex codes** then restart: `npm run dev`

### 3. Update Content (10 minutes)
- **Navbar**: `src/components/layout/Navbar.jsx`
- **Hero**: `src/components/sections/HeroSection.jsx`
- **Features**: `src/components/sections/FeaturesSection.jsx`
- **Services**: `src/components/sections/ServicesSection.jsx`
- **Stats**: `src/components/sections/StatsSection.jsx` (update numbers)
- **Testimonials**: `src/components/sections/TestimonialsSection.jsx`
- **CTA**: `src/components/sections/CTASection.jsx`
- **Footer**: `src/components/layout/Footer.jsx`

### 4. Adjust Animation Speed (5 minutes)
- **File**: `tailwind.config.js`
- **Section**: `animation:` object
- **Examples**: 
  - `shine: 'shine 3s ease-in-out infinite'` (change `3s`)
  - `'gradient-flow': 'gradientFlow 8s ease infinite'` (change `8s`)

### 5. Add New Pages (20 minutes)
- Create: `src/pages/YourPage.jsx`
- Import sections and compose
- Add route in `src/App.jsx`
