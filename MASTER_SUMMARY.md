## 💡 CUSTOMIZATION EXAMPLES

### Change Gold Color
```javascript
// tailwind.config.js
gold: {
  light: '#FFF3B0',    // ← Change hex
  DEFAULT: '#E6C200',
  mid: '#C9A84C',
  dark: '#A67C00',
}
```

### Change Peacock Color
```javascript
// tailwind.config.js
peacock: {
  deep: '#0F3D3E',     // ← Change hex
  blue: '#0A6E6E',
  green: '#14B8A6',
  light: '#1ECDB0',
}
```

### Change Animation Speed
```javascript
// tailwind.config.js
animation: {
  shine: 'shine 3s ease-in-out infinite',  // Change 3s
  'gradient-flow': 'gradientFlow 8s ease infinite',  // Change 8s
}
```
